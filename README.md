# AI Visibility Checker

You can rank on Google and still be invisible in ChatGPT.

A free Claude skill from the [AI Ranking community](https://skool.com/ai-ranking-free).

## What it does

1. Checks whether ChatGPT, Gemini, Google AI Overviews and Perplexity cite or mention you.
2. Compares you against your competitors on the same questions.
3. Lists the gaps (questions they win and you don't) and the ones you already own.

## Install

**Claude desktop app or claude.ai:** download [ai-visibility-checker.zip](https://github.com/NicoSKOOL/ai-visibility-checker/releases/latest/download/ai-visibility-checker.zip) (don't unzip it), then go to Settings > Capabilities > Skills > Upload skill. Also turn on Code execution and file creation.

**Claude Code:**

```bash
git clone https://github.com/NicoSKOOL/ai-visibility-checker ~/.claude/skills/ai-visibility-checker
```

## Data

- **Needs:** the [DataForSEO](https://app.dataforseo.com/?aff=182182) connector with AI Optimization. There's no free source for citation data, and the skill won't guess.
